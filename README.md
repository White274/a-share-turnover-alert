# A股10:00与10:15定点量能报告

本仓库通过 GitHub Actions 在云端运行，不需要在个人电脑安装 Python、Vibe-Trading、Docker 或其他软件，也不要求电脑开机。

## 固定时点

- 北京时间 10:00
- 北京时间 10:15

## 数据规则

- 数据源：东方财富 5 分钟指数 K 线 JSON 接口
- 沪市口径：`1.000001`（上证综指）
- 深市口径：`0.399001`（深证成指）
- 成交额字段：`f57`
- 只累加目标时点前已经封口的 5 分钟 K 线
- 禁止使用新闻快讯、搜索摘要、实时快照、估算、插值或反推

## 自动生成文件

- `reports/latest_1000.md`
- `reports/latest_1015.md`
- `reports/YYYY-MM-DD/1000.md`
- `reports/YYYY-MM-DD/1015.md`
- `data/history.csv`

ChatGPT自动化只读取两份`latest`报告，并核验交易日期、目标时点和`success`状态。

## 定时方式

工作日北京时间：

- 09:57启动10:00任务，脚本等待至K线封口后取数
- 10:12启动10:15任务，脚本等待至K线封口后取数

GitHub Actions可能因平台负载稍有延迟，但报告始终读取指定时点已经封口的K线，不会使用晚几分钟的实时快照冒充目标时点。
